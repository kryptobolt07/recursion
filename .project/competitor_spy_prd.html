01
Channel Analysis Engine
A system to understand content themes, audience signals, and performance patterns for any YouTube channel.
1.1 — Niche & Theme Overview
Block chart core
Proportional horizontal bar showing channel split across auto-detected niches (e.g. Linux & OS 38% / Hardware 27% / Dev Tools 21% / Opinion 14%). Each block is clickable and opens the niche detail page.
Niche metrics table core
Per niche: upload share %, view share %, avg views, avg video length, estimated retention %, view-to-upload efficiency delta (over/under-performing). Sortable by any column.
Niche auto-detection ai
Titles + descriptions + transcripts are embedded and clustered (HDBSCAN). Cluster labels are generated by LLM from representative video titles. No manual tagging required.
Sub-niche drill-down core
Each niche expands into granular sub-niches (e.g. Linux → Distro Reviews / Terminal Setup / NixOS / Window Managers). Each sub-niche shows estimated avg views and retention.
Channel health score new
Composite 0–100 score across content quality, engagement rate, growth momentum, and upload consistency. Displayed globally and broken down per niche.
1.2 — Content DNA
Title pattern analysis core
What linguistic patterns dominate: % using numbers, % starting with "How I", % question format, avg word count, avg character length. Shown globally and per niche — patterns differ significantly across content types.
Thumbnail style profile core
Face present %, bold text overlay %, avg word count on thumbnail, dominant color palette extracted via CV. Shown globally and per niche.
Video length distribution core
Bar chart across buckets (<5m / 5–10m / 10–20m / 20–30m / 30m+). Peak bucket called out. Broken down per niche — hardware reviews are longer, opinion pieces are shorter.
Hook & format patterns new
Detected from transcripts: does the channel open with a question, a stat, a story, or a demonstration? What % of videos use a listicle structure vs. narrative? Correlate with retention.
1.3 — Performance & Views Breakdown
Views distribution bar core
Proportional bar showing how total channel views are split across niches. Compared against upload share — a niche with 21% of uploads but 38% of views is a clear priority signal.
Upload vs view efficiency new
Side-by-side dual-bar per niche showing upload % vs view %. Surplus/deficit labeled (e.g. Hardware: +11% view surplus — over-indexed). Flags which niches to double down on and which to deprioritize.
Top performing videos core
Global list of top videos ranked by views. Per-niche top 3 videos shown on niche detail page. Displays title, view count, niche tag, and a performance badge (outlier / typical / underperformer).
Viral outlier detection new
Videos that significantly exceeded channel average are flagged. LLM inspects title/thumbnail/topic of outliers to identify what drove the spike — informs strategy recommendations.
1.4 — Audience Signals
Sentiment breakdown core
Comment tone classified as positive / neutral / critical. Shown as a proportional bar globally and per niche. Sentiment varies by content type — opinion content typically generates more critical engagement.
Viewer asks (topic demand) core
LLM extracts recurring requests from comments ("Can you cover X?", "Please make a video on Y"). Displayed as tags globally and per niche. Directly feeds Strategy Generation module.
Age breakdown core
Bar chart across 6 age bands (13–17 / 18–24 / 25–34 / 35–44 / 45–54 / 55+). Shown globally and per niche. Audience age differs by niche — dev tools skews 25–34, hardware skews 18–24.
Country / geography core
Top countries by viewer share with proportion bars. Shown globally and per niche. Signals subtitle/localization opportunities (e.g. strong Spanish-speaking minority in Linux content).
Language distribution new
Derived from comment language detection. Separate from country — a US viewer may comment in Spanish. Flags non-English audience segments the creator may be underserving.
Praise & complaint tags new
LLM extracts what viewers specifically praise ("no fluff", "real benchmarks", "honest") and complain about ("audio quality", "too short", "wants longer form"). Actionable qualitative signals.
1.5 — Upload Cadence
Global cadence stats core
Avg days between uploads, consistency index (variance score), best performing upload day, longest gap in past 12 months and its impact on views.
Monthly upload calendar core
Heatmap-style calendar showing upload density by month. Color-coded by volume. Gaps and bursts are immediately visible.
Stacked cadence by niche core
Monthly bar chart where each bar is stacked by niche color, showing how content mix has shifted over time. Reveals if a creator has been gradually pivoting toward a particular niche.
Per-niche rhythm core
Mini bar chart per niche showing upload volume by month. Reveals cadence patterns specific to each content type (e.g. hardware reviews cluster around product launch seasons).
Day-of-week heatmap new
Which days the channel publishes vs. which days get the most views. Identifies best performing upload windows. Compared against niche-level averages from competitor data.
02
Competitor Discovery Module
Auto-identifies relevant competitors without manual input, then structures a full competitive landscape for analysis.
2.1 — Discovery & Ranking
Auto-discovery core
No manual input required. System derives channel niche fingerprint from Module 1, then queries YouTube API for channels with overlapping topic clusters, keyword co-occurrence, and audience overlap signals.
Global top creators core
Ranked list of top creators in the channel's overall space — sorted by subscriber count, avg views, and engagement rate. Each shows similarity score to the analyzed channel.
Per-niche top creators core
For each detected niche (e.g. Linux content, hardware reviews), a separate ranked list of top competitors in that specific sub-space. A creator may be a competitor in one niche but not another.
Content similarity score core
0–100 score computed from embedding distance between channels' video title/description corpora. Broken down by niche — a competitor may be highly similar in Linux content but diverge on hardware.
Competitive landscape map new
2D scatter plot positioning all discovered competitors: X-axis = channel size (subscribers), Y-axis = engagement rate. The analyzed channel is plotted with you vs. them clearly visible. Reveals whitespace and saturation zones.
2.2 — Performance Comparison
Head-to-head metrics core
Side-by-side table: your channel vs. selected competitor across subscribers, avg views, view/sub ratio, engagement rate, upload frequency, consistency index, and estimated monthly views.
Engagement rate benchmarking core
Your engagement rate plotted against niche average and top performer. Shows whether underperformance is a content issue or a distribution issue.
Viral pattern detection core
Identifies videos across competitor channels that significantly outperformed that channel's baseline. Clusters them by topic, format, title structure, and thumbnail style — extracts what drove the viral spike.
Growth trajectory comparison new
Estimated subscriber and view growth curves over past 12 months for you and top 3 competitors plotted together. Reveals who is accelerating, plateauing, or declining in the space.
2.3 — Content & Format Analysis
Similar videos comparison core
For each of your videos, surface the most similar competitor videos (by topic embedding). Show performance delta: their views vs. your views on the same topic. Reveals execution gaps.
What works for them core
LLM summarizes patterns in a competitor's top-performing content: which topics, which formats (tutorial / review / opinion), which title structures, what upload cadence. Presented as a competitor content playbook.
Content gap analysis new
Topics competitors cover that you don't, and topics you cover that they don't. The former is threat/opportunity detection; the latter is your moat. Visualized as a Venn-style overlap matrix.
Thumbnail style comparison core
Side-by-side breakdown of your thumbnail DNA vs. competitor: face %, text density, color temperature, contrast level. Flags stylistic divergence from high-performing competitors in the niche. Feeds thumbnail suggestions in Module 5.
Title formula comparison new
Competitor's title patterns extracted and compared to yours. Highlights formulas they use on high-performing videos that you haven't tried. Directly feeds Title Optimization in Module 5.
2.4 — Audience Overlap
Audience sentiment comparison new
Your positive/neutral/critical sentiment breakdown compared to competitor. If their audience is more satisfied on the same topic, the gap in tone or depth is actionable.
Collaboration opportunity flag new
Identifies channels that are non-competing (different niche or tier) but share audience demographics. High-potential collab candidates ranked by audience similarity score.
03
Data Extraction & Structuring Layer
The infrastructure that collects, normalizes, and stores all raw data that Modules 1, 2, 4, and 5 depend on.
3.1 — Data Sources
YouTube Data API v3 core
Channel metadata, video list, per-video statistics (views, likes, comments), comment threads (up to API quota), channel keywords and category. Rate limit managed via quota-aware scheduler.
Auto-caption transcripts core
YouTube auto-generated captions fetched via youtube-transcript-api. Used for topic clustering, hook detection, and LLM summarization. Falls back gracefully when unavailable.
Thumbnail images core
Thumbnail URLs fetched from API. Processed via CV pipeline: face detection (MediaPipe), text detection (EasyOCR), dominant color extraction (k-means on pixel sample), contrast scoring.
Comment sampling core
Top-level comments fetched for a sample of videos (configurable, default: top 50 videos by views, up to 100 comments each). Stratified across niches to ensure representative coverage.
3.2 — Processing & Schema
Normalization layer core
All numeric metrics normalized to channel-relative and niche-relative baselines before storage. Raw numbers are stored alongside normalized scores. Prevents misleading cross-channel comparisons on absolute values.
Deduplication & caching core
Video-level and channel-level cache with TTL (default 24h). Re-analysis requests refresh only stale records. Prevents redundant API calls and stays within quota limits.
Embedding store core
Video-level embeddings (title + description + transcript excerpt) stored in a vector DB (Pinecone or Chroma). Used by clustering, similarity search, and competitor matching. Updated incrementally on new video fetch.
Structured output schema core
All LLM outputs (cluster labels, sentiment summaries, viewer ask extraction, viral pattern analysis) are structured into typed JSON schemas before storage. No free-text blobs reach the frontend directly.
Noise handling new
Incomplete data handled gracefully: missing transcripts fall back to title+description only, missing view counts use channel median, bot-like comments filtered by account age and repetition score before sentiment analysis.
04
Pattern Recognition Engine
Identifies trends, successful strategies, anomalies, and cross-channel signals that no single data point reveals on its own.
4.1 — Trend Detection
Niche-level topic trends core
Topics appearing with increasing frequency across competitor channels in the past 90 days. Ranked by velocity (rate of upload increase) and traction (views generated). Distinguishes rising trends from established staples.
Format trend detection core
Is the niche shifting toward longer or shorter content? Are listicles outperforming narratives? Are Shorts gaining traction? Cross-channel format performance tracked over time.
Emerging sub-niche radar new
Detects sub-topics with low current saturation but rising search and upload frequency. These are whitespace opportunities — topics the analyzed channel could own if they move early.
4.2 — Performance Pattern Analysis
Success pattern extraction core
What do the top-performing 10% of videos across the niche have in common? Title structure, length bucket, thumbnail style, upload day, topic cluster. Patterns extracted via frequency analysis + LLM synthesis.
Anomaly detection core
Videos that dramatically over- or under-performed against channel baseline and niche average. Investigated for causal factors: external promotion, trending topic, algorithm recommendation, or title/thumbnail outlier.
Engagement rate decomposition new
Separates like rate, comment rate, and share-proxy signals. High views + low engagement = passive audience. High engagement + moderate views = cult following. Different strategic implications for each profile.
Retention vs length correlation new
Estimated retention plotted against video length per niche. Identifies the sweet-spot length for each content type — where retention is highest relative to the time invested per video.
4.3 — Cross-Channel Signals
Winning cadence patterns core
Upload frequency and day-of-week patterns of top-performing channels in the niche. Identifies whether the niche rewards consistency or whether quality-over-quantity strategies outperform.
Thumbnail CTR signal core
Correlates thumbnail style attributes (face presence, text density, color temperature) with view count relative to subscriber base across competitor channels. Derives what drives higher implied CTR in this niche.
05
Strategy Generation System
Converts all analysis into concrete, actionable outputs — from growth roadmaps to video-level execution tools.
5.1 — Channel Strategy
Growth roadmap core
30 / 60 / 90-day phased plan. Phase 1: double down on highest-efficiency niches. Phase 2: test emerging sub-niches identified in Pattern Engine. Phase 3: expand into adjacent audience territory. Each phase has specific output targets.
Niche mix recommendation core
Based on upload/view efficiency analysis and competitor positioning, recommends the optimal content mix (e.g. "Increase Linux & OS from 38% to 50%, reduce Opinion to 8%, pilot Shorts in Dev Tools"). Explained with data rationale.
Competitive positioning new
Where does the channel have a defensible advantage vs. competitors? Where are they being commoditized? Recommends a positioning angle (e.g. "own the no-fluff Linux for developers lane") grounded in audience signal data.
5.2 — Video Ideas
Idea generation core
10–20 video concepts generated per session. Each idea includes: working title, target niche, hook suggestion, content angle, target keyword, estimated competition level (low/med/high), urgency flag (trending / evergreen).
Idea sourcing signals ai
Ideas are generated from four sources weighted together: (1) viewer asks extracted from comments, (2) competitor content gaps, (3) trending topics from Pattern Engine, (4) high-retention sub-niches with low upload saturation.
Content calendar output new
Arranges generated ideas into a suggested posting calendar respecting the recommended cadence, niche mix targets, and best upload days. Exportable as a structured list.
5.3 — Title Optimization
Existing title rewrite core
For any existing published video, generates 3–5 alternative title variants applying patterns from top-performing videos in the niche. Each variant tagged with the formula it uses (number-lead / how-I / provocative question / etc.).
Title score & explanation new
Current title scored against niche patterns (clarity, curiosity gap, keyword alignment, length). Explanation of why it may be underperforming and what the rewrite fixes specifically.
A/B variant suggestions new
Two structurally distinct variants per rewrite (not just synonyms). One optimized for search (keyword-forward), one for browse (curiosity/emotional). Creator can test both and track which performs.
5.4 — Thumbnail Strategy
Thumbnail suggestion core
Text brief describing the ideal thumbnail for a given video: recommended composition, whether to include face, suggested text overlay (word count, placement), color direction relative to channel brand and niche CTR patterns.
Competitor thumbnail comparison core
For the same topic, surfaces competitor thumbnails and scores them against the channel's current style. Highlights what attributes the higher-performing thumbnails share that current thumbnails lack.
AI thumbnail generation brownie
Image generation prompt constructed from the thumbnail brief, fed to an image model (DALL-E / Stable Diffusion). Output is a draft thumbnail concept, not a final asset. Intended as a creative starting point.
5.5 — Posting Strategy
Optimal schedule core
Recommended upload days and times based on: (1) when the channel's own videos historically get the most traction, (2) when competitor videos in the niche get peak engagement, (3) audience timezone distribution from geography data.
Frequency recommendation core
Whether to increase, maintain, or decrease upload frequency based on consistency score, niche patterns, and performance trends. Includes a quality-vs-quantity trade-off assessment specific to the niche.
Ad strategy hints brownie
Topics and formats that historically attract higher advertiser CPM in the niche (tech reviews, financial content, etc.). Recommends which video types to prioritize for monetization vs. which are better for audience growth.
5.6 — Performance Simulation
Video performance forecast core
Given a title and/or script outline, generates an estimated performance curve: projected views at 24h / 7d / 30d benchmarks, confidence range, comparison against channel's own average for that niche. Based on similar historical videos.
Simulation graph core
Line chart showing projected view growth curve with confidence band (optimistic / expected / conservative). Channel baseline overlaid for context. Gives the creator a tangible sense of expected reach before publishing.
Input sensitivity analysis new
How much does the forecast change if the title follows a high-performing formula vs. a weak one? If published Tuesday vs. Sunday? Shows which decisions have the highest leverage on predicted outcome.
Script-to-forecast brownie
Full script or outline submitted → LLM extracts topic, estimated length, content depth, hook strength → these signals are fed into the performance model alongside title quality. More sophisticated input = more refined forecast.
